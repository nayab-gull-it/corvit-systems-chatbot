## 📌 Post Option 1: Technical Depth & Architectural Innovation (Recommended)
*Best for attracting AI engineers, tech leads, recruiters, and fellow developers.*

```markdown
Building AI applications is easy. Building resilient, production-ready AI systems that NEVER fail under real user traffic is where real software engineering begins. 💡

Recently, as part of my AI training project, I developed the official AI Academic Advisor & Interactive Platform for Corvit Systems Rawalpindi (Zarwar Center, 6th Road).

Rather than building just another basic LLM wrapper, I wanted to solve the real-world challenges student platforms face: high API latency, rate limits, bilingual queries, and missing visual context.

Here is the architectural breakdown of what I built:

🔹 1. Multi-Tier Cascading Model Fallback:
To ensure 100% availability with zero unhandled errors, every student query runs through a cascading router:
- Tier 1: Groq GPT-OSS 120B (Deep Reasoning & Comprehensive Guidance)
- Tier 2: Groq GPT-OSS 20B (Sub-second High-Speed Fallback if Tier 1 hits limits)
- Tier 3: Qwen 3.8 27B (High-Resilience Open Backup)
- Tier 4: Local Grounded Dataset Engine (Offline / Deterministic RAG)

🔹 2. Contextual Visual Recommendations & High-Res Lightbox:
When students ask about batch timetables, fees, Cisco labs, or certifications, the AI dynamically recommends verified official flyers and lab photos. Clicking any preview opens an interactive, full-screen Lightbox modal with zoom and direct WhatsApp booking.

🔹 3. Two-Way Bilingual Voice AI (Roman Urdu + English):
Pakistani students frequently write or speak in Roman Urdu ("CCNA ki fee kitni hai aur batch kab start hoga?"). The system features native speech-to-text dictation and speech-synthesis audio readout with instant play/stop controls.

🔹 4. Full-Funnel WhatsApp Admissions Bridge:
Every response generates a pre-filled, contextual WhatsApp link directly to the Rawalpindi campus desk (0311-1444473), converting student curiosity into real enrollment inquiries.

🔹 5. Developer Telemetry & UX Polish:
- Live latency and model execution badges on every message (e.g., ⚡ Groq 120B • 1.4s)
- 1-Click response copying with animated tooltips
- Wide / Fullscreen desktop expand mode
- Complete session export to formatted Markdown (.md)

Tech Stack: Vanilla JavaScript, Tailwind CSS, Netlify Serverless Functions, Groq AI API, Web Speech API, Grounded RAG.
```

## 🎬 45-Second Demo Video Recording Guide

When posting on LinkedIn, a crisp **30 to 45-second screen recording video** gets up to **5x higher impressions** than text alone.

### Recommended Screen Flow:
1. **Seconds 00–08:** Show the landing page with the glowing floating robot beacon in the bottom-right corner. Click it to reveal the smooth slide-in widget.
2. **Seconds 08–20:** Click the chip: *"💰 CCNA Fee & Free Linux"* or speak into the microphone in Roman Urdu. Show the response streaming in word-by-word with the telemetry badge (`⚡ Groq GPT-OSS 120B • 1.4s`).
3. **Seconds 20–30:** Scroll down to the recommended image card (`[IMAGE:ccna_flyer]` or `[IMAGE:schedule_flyer]`). Click "View Full" to show the sleek **Lightbox Modal** opening with the high-res view.
4. **Seconds 30–38:** Click the **Expand Mode** button in the header to demonstrate the wide desktop view. Click the **Copy** button to show the animated "Copied!" checkmark.
5. **Seconds 38–45:** Click the **"Book Seat on WhatsApp"** button to show the pre-filled message pop-up, proving end-to-end user acquisition.

### Recommended Free Tools:
- **Loom** / **OBS Studio** / **Windows Snipping Tool (Win + Shift + R)**
- Set resolution to 1080p.
- Ensure browser zoom is at 100% or 110% for crisp typography.
